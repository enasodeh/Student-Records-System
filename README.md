# Student Records System

A desktop application developed using **C++ and Qt** for working with student academic records and displaying student information and results.

The project demonstrates practical use of object-oriented programming, Qt GUI development, data processing, and the organisation of a larger application into separate components.

## Project Components

The repository contains two main components:

### GetStudent

`GetStudent` focuses on retrieving and displaying individual student information through a Qt-based graphical user interface.

### StudentList

`StudentList` extends the student-record functionality by working with a collection of student records and presenting academic information through a graphical interface.

## Features

* Retrieve and display student information.
* Work with multiple student records.
* Display academic results through a desktop GUI.
* Process student academic data.
* Organise student information into structured records.
* Provide an interactive interface using Qt Widgets.

## Running the Project

### GetStudent

1. Install **Qt** and Qt Creator.
2. Open the `GetStudent` folder.
3. Open `Q1_GetStudent.pro` in Qt Creator.
4. Configure a compatible Qt Desktop kit.
5. Build and run the project.

### StudentList

1. Open the `StudentList` folder.
2. Open `StudentList.pro` in Qt Creator.
3. Configure a compatible Qt Desktop kit.
4. Build and run the project.
